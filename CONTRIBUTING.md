# 🤝 Guía de Contribución y Sugerencias — SaaS Smart Engine

¡Gracias por tu interés en mejorar **saas-smart-engine**!

---

## 🔒 Política de Protección del Repositorio

* **Acceso de Solo Lectura / Descarga:** Los usuarios externos pueden clonar, instalar vía `npx saas-smart-engine` o usar este motor libremente en sus propios proyectos.
* **Prohibido el Push Directo:** La rama principal (`main`) está blindada. Nadie puede modificar directamente el código del repositorio oficial.

---

## 💡 Cómo Enviar Sugerencias y Mejoras

Si deseas proponer una nueva funcionalidad, corrección de bug o mejora en las Skills:

### Opción 1: Abrir un GitHub Issue (Recomendado para ideas)
1. Ve a la pestaña **[Issues](../../issues)** de este repositorio.
2. Haz clic en **New Issue** y describe tu sugerencia o el problema detectado.
3. El equipo mantenedor revisará la idea y la implementará si aporta valor a la comunidad.

### Opción 2: Enviar un Pull Request (PR) (Para contribuciones de código)
1. Haz un **Fork** de este repositorio a tu propia cuenta de GitHub.
2. Crea una rama para tu mejora (`git checkout -b mejora/mi-sugerencia`).
3. Realiza tus cambios y envía un **Pull Request (PR)** hacia nuestra rama `main`.
4. El mantenedor principal y la IA revisarán, probarán y aprobarán Quirúrgicamente el PR antes de fusionarlo.

---

## 📋 Criterios de Aprobación de PRs
* El código debe pasar linters y pruebas automáticas.
* No se aceptan cambios destructivos o dependencias innecesarias.
* Debe mantener veracidad absoluta (sin alucinaciones) y formato Markdown limpio.
