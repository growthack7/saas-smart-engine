# 🧠 AGENTS.md — SaaS Smart Engine

> **Doctrina Maestra para la Construcción de Plataformas SaaS con Agentes Inteligentes.**

---

## ⚡ Consigna y Filosofía Maestra

Este repositorio dota a cualquier agente de IA de la arquitectura, reglas y **Skills Especializadas** para construir o mejorar plataformas SaaS sin fallos, de forma inteligente y con barandas de seguridad. Permite obtener resultados de nivel superior en diseño UI/UX (Bento Grid, Glassmorphism), SEO-GEO, seguridad, velocidad, monetización con Stripe y memoria en grafos con ahorro de tokens de hasta 20x.

---

## 📐 Las 8 Pilar-Leyes de SaaS Smart Engine

1. **🗺️ Indexación y Memoria en Grafos:** Navegación en mapas semánticos para ahorrar hasta 20x tokens sin re-leer archivos redundantes.
2. **🧠 Aprendizaje Evolutivo Doble:** Consulta obligatoria de `MEMORY.md` al iniciar cada sesión (preferencias y correcciones aprendidas) y `BUG_HISTORY.md` antes de depurar (histórico de fallos resueltos).
3. **⭐ Evaluación y Búsqueda de Skills de Alta Reputación:** El motor analiza el proyecto o PRD existente, busca en la web/comunidad las habilidades (skills) más votadas, calificadas y mantenidas, y las instala/integra automáticamente tras pasar por el Security Gate.
4. **🎨 Diseño UI/UX Nivel Superior:** Interfaces de nivel industrial (Bento Grid modular, Glassmorphism sutil, tipografía moderna, respuestas <100ms y accesibilidad A11y).
5. **🔬 Bucle Autónomo "Probar ➔ Detectar ➔ Arreglar":** Verificación E2E de usuario real mediante herramientas MCP para entregar software estable y probado a producción.
6. **🗄️ Resiliencia de BD & Zero-Downtime:** Migraciones seguras en PostgreSQL/pgvector, connection pooling (PgBouncer) y contenedores Docker en VPS propia.
7. **🎯 Ejecución Atómica y Specs-First:** Desarrollo guiado por PRD generado con *Superpowers*, avanzando "una sola cosa a la vez" para eliminar regresiones.
8. **🏛️ Veracidad Absoluta y Método Stanford:** Cero alucinaciones o simulaciones falsas. Siempre plantear 3 alternativas (Genio, Rompe Paradigmas, Senior +20 años) para resolver problemas complejos y combinarlas para la solución suprema.
